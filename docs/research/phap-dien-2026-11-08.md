# Bộ pháp điển as a taxonomy source (2026-11-08)

Checked by fetching the live portal and parsing the 2023 offline package.

- Published 5 November 2024: 45 chủ đề, 271 đề mục, free to use, central-level
  in-force documents only. Source:
  https://xaydungchinhsach.chinhphu.vn/cong-bo-bo-phap-dien-viet-nam-119241105183017898.htm
- `phapdien.moj.gov.vn` is now a React application titled "Phần mềm hỗ trợ
  Pháp điển" calling `https://vbpl-bientap-gateway.moj.gov.vn/api`; every API
  path returns 401 without a token. The former public pages
  (`/Pages/chi-tiet-bo-phap-dien.aspx`, `/qt/tintuc/...`) return 404. The VBPL
  footer still links to the dead page.
- Official offline package `BoPhapDienDienTu.zip` (33 MB, dated 2023-11-21) is
  mirrored at https://github.com/definev/phapdien under `data/`. Contents:
  `jsonData.js` with `jdChuDe` (45), `jdDeMuc` (293 entries, 11 marked "loại
  bỏ"), `jdAllTree` (90,316 nodes with MAPC position codes); `demuc/*.html`
  (293 files) with classes `pChuong`, `pDieu`, `pGhiChu`, `pNoiDung`.
- Parsed: 86,388 articles placed in the tree, each with a link to
  `vbpl.vn/TW/Pages/vbpq-toanvan.aspx?ItemID=<id>#<anchor>`; 6,523 distinct
  ItemIDs. Article kinds: TT 40,963; NĐ 22,008; LQ 15,210; TL 3,545; QĐ 3,013;
  PL 747; NQ 738; others under 100.
- Finance subjects in the tree: chủ đề 22 "Ngân hàng, tiền tệ" has 6 đề mục
  (Bảo hiểm tiền gửi; Các công cụ chuyển nhượng; Các tổ chức tín dụng; Ngân hàng
  Nhà nước Việt Nam; Ngoại hối; Phòng, chống rửa tiền). Chứng khoán is under 34;
  An ninh mạng under 1. No đề mục for personal data, payments or fintech.
