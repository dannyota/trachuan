**Goal:** The website: public pages without an account, Google sign-in through the server's login routes, search and the document reader for signed-in users, and the account page, in Vietnamese with optional English.

**Architecture:** `apps/web` is Nuxt 4 SSR (ADR 0007) with Pinia, reka-ui and Tailwind, calling the Go server's `/api/v1` on the same origin through an `openapi-fetch` client generated from `packages/schema/openapi.yaml`. Public pages are cached by Nitro route rules; signed-in pages fetch with the session cookie and the CSRF token from `GET /api/v1/me`.

## Global Constraints

- Questions are never stored (ADR 0002): search sends the query only in a `POST` body from the browser; the query never appears in a URL, route, page title, history entry, `localStorage`, `sessionStorage`, a cookie, analytics or a log line, and signed-in search results are never server-rendered or cached.
- Same origin as the Go server (web.md "Routing"); local development on `http://localhost:3000` with the dev proxy for `/api/*` to `http://127.0.0.1:8080` and `SERVER_PUBLIC_URL=http://localhost:3000`.
- Nitro route rules cache only public routes (`/`, `/connect`, `/sources`, `/privacy`, `/terms`, `/llms.txt`) for 600 s, keyed by path and the `lang` cookie; signed-in routes send `Cache-Control: no-store` and are never cached.
- Unsafe API calls send `X-CSRF-Token` from `GET /api/v1/me`; a 401 leads to `/api/v1/auth/google/start?next=<current path>` following the web-api.md `next` rules; a 403 `csrf_rejected` refetches `/api/v1/me` once and retries once.
- Language: cookie `lang` (`vi` default, `en`), read on the server for SSR; interface strings in `apps/web/i18n/{vi,en}.ts`; legal text, citations and document numbers are never translated.
- CSP with Nuxt nonces: `default-src 'self'`; scripts and styles only with the nonce or `'self'`; fonts and images `'self'`; `connect-src 'self'`; `frame-ancestors 'none'`; no third-party host anywhere. Fonts self-hosted (Be Vietnam Pro for interface, a serif for law, a monospace for numbers; OFL licences kept beside the files).
- Legal text and any API string render as text, never through `v-html`.
- Personal tokens are shown once on creation, kept only in component state, and cleared on navigation; never stored in Pinia, storage or logs.
- Component and source files at most 400 lines; tests `<subject>.test.ts` (Vitest) and `<feature>[-<scenario>].spec.ts` (Playwright).

## Review Focus

- A query leaking through a URL, history, storage or a server render: Task 4 `search-privacy.spec.ts` and `search-state.test.ts`.
- A signed-in response cached by Nitro or served to another visitor: Task 1 `route-rules.test.ts`, Task 6 `account-no-store.spec.ts`.
- An unsafe call without the CSRF token, or a retry loop on 403: Task 2 `api-csrf.test.ts`.
- API or legal text interpreted as HTML: Task 5 `reader-text.test.ts`.
- A personal token surviving after the creation dialog closes: Task 6 `token-once.spec.ts`.
