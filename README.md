# traquydinh

A citable corpus of Vietnamese law for AI agents (over MCP) and people (on the
web). Evidence only: verbatim provisions with citations, validity and amendment
context, organized in a subject tree so an agent can narrow before it searches.

Status: the corpus pipeline core and VBPL ingest are built
([architecture](docs/architecture.md)). Read the [design](docs/design/README.md)
and the [documentation map](docs/README.md). Agents read [AGENTS.md](AGENTS.md).

Successor to [banhmi](https://github.com/dannyota/banhmi); reuses its data, not
its code.
